Le fichier est vérifié ici, puis enregistré dans le dépôt GitHub. Les agendas sont générés et mis en ligne dans la minute qui suit.

Clé d’accès GitHub

Pour enregistrer un fichier dans le dépôt, le site a besoin d’une clé qui l’y autorise. Elle est demandée une seule fois et ne quitte pas cet appareil, sauf vers GitHub.

Créer la clé
  1. Ouvrez la création de clé (fine-grained token) sur GitHub, connecté au compte propriétaire du dépôt.
  2. Donnez-lui un nom, par exemple « Plannings accueil », et une date d’expiration.
  3. Dans « Repository access », choisissez « Only select repositories », puis planning-accueil.
  4. Dans « Permissions », réglez Contents sur « Read and write » et Actions sur « Read-only ».
  5. Validez, puis copiez la clé affichée (elle commence par github_pat_).
